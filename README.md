# FoxBridge

<img src="development/FoxBridge.WinUI/Assets/AppIcon.png" width="80" alt="Иконка FoxBridge">

В Firefox есть [бесплатный встроенный VPN](https://support.mozilla.org/en-US/kb/built-in-vpn) с лимитом 50 ГБ в месяц для трафика браузера. Отдельный [Mozilla VPN для всего устройства](https://blog.mozilla.org/en/firefox/built-in-vpn/) доступен по платной подписке.

FoxBridge создан для использования доступа Firefox VPN в Codex, Claude Code, браузере и других приложениях Windows. Приложение получает данные доступа из выбранного профиля Firefox и поднимает локальный HTTP прокси. Интерфейс объединяет выбор сервера, квоту, проверку IP и запуск приложений.

Это неофициальный клиент. Доступность VPN и квота зависят от аккаунта Mozilla.

## Требования

* Windows 11 x64, на которой проверена текущая сборка.
* [.NET Runtime 10 x64](https://dotnet.microsoft.com/download/dotnet/10.0).
* [Windows App Runtime 2.6.4 x64](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads).
* [Python 3.12 или новее](https://www.python.org/downloads/windows/), доступный через PATH.
* Установленный Firefox и профиль с авторизацией Mozilla и доступным встроенным VPN.
* Для TUN нужны права администратора.

## Запуск отдельных приложений:
1. Кнопка терминала открывает PowerShell с адресом локального прокси и переменной TZ. Их наследуют дочерние процессы.
2. «Открыть Firefox» использует тот же профиль, который загружен для получения данных VPN. Но **локаль и TZ в него не прокидываются** - браузер детектит RemoteAgent и WebDriver и переходит в режим "мной управляет ИИ агент", в котором много сайтов просто не пропускают через cloudflare подтверждение. Для спуфа часового пояса и региона можно установить любое расширение, главное - это синхронизировать панные с выбранным VPN сервером. Просто перед началом работы в web версии чего угодно заходим [сюда](https://ip.net.coffee/claude/) и выставляем как надо. 

## Направление всего трафика через TUN:
TUN направляет TCP интернет соединений в локальный прокси. DNS передаётся через HTTPS внутри туннеля. Остальной UDP, попавший в TUN, блокируется. Игры, звонки и приложения, которым необходим UDP, могут не работать. Loopback, локальная сеть, специальные маршруты и явная привязка к другому интерфейсу могут обходить TUN.
При отключении или аварии TUN обычный доступ Windows к сети возвращается. Постоянный kill switch отсутствует. После смены Wi-Fi, Ethernet или другого VPN переподключите TUN. Фоновые загрузки тоже расходуют квоту Mozilla. TUN не меняет часовой пояс, язык Windows и настройки браузеров.

HTTP и HTTPS идут через локальный прокси FoxBridge. Системный TUN для этого не требуется. WebRTC, HTTP/3 и предзагрузка DNS временно отключаются. Звонки через WebRTC могут не работать.

### Важно: авторизация в Codex и Claude

> [!IMPORTANT]
> Для входа из CLI подготовьте браузер заранее. Страница авторизации должна открываться через нужное подключение.

1. Сделайте Firefox браузером по умолчанию в Windows.
2. Заранее запустите Firefox с тем же профилем, который используется в FoxBridge.
3. Для обычного Firefox включите встроенный VPN с той же локацией, которая выбрана в FoxBridge. Оставьте его включённым до завершения входа.
4. Запускайте авторизацию из защищённого терминала FoxBridge и убедитесь, что ссылка открылась в подготовленном браузере.

Если используется кнопка «Открыть Firefox», сначала закройте обычные окна этого профиля, затем запустите его через FoxBridge. В этом случае браузер уже получает прокси приложения. Запуск не меняет браузер по умолчанию и не гарантирует выбор профиля для внешней ссылки. Не включайте одновременно несколько маршрутов без проверки фактического выхода.

## Оценка и ограничения

Net.Coffee получает проверяемый публичный IP и возвращает собственную оценку рисков. Это не рейтинг Anthropic.
