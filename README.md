# FoxBridge

<img src="development/FoxBridge.WinUI/Assets/AppIcon.png" width="80" alt="Иконка FoxBridge">

В Firefox есть [бесплатный встроенный VPN](https://support.mozilla.org/en-US/kb/built-in-vpn) с лимитом 50 ГБ в месяц для трафика браузера. Отдельный [Mozilla VPN для всего устройства](https://blog.mozilla.org/en/firefox/built-in-vpn/) доступен по платной подписке.

FoxBridge создан для использования доступа Firefox VPN в Codex, Claude Code, браузере и других приложениях Windows. Приложение получает данные доступа из выбранного профиля Firefox и поднимает локальный HTTP прокси. Интерфейс объединяет выбор сервера, квоту, проверку IP и запуск приложений.

Это неофициальный клиент. Доступность VPN и квота зависят от аккаунта Mozilla.

## Возможности

* Выбор профиля Firefox и сервера VPN.
* Локальный HTTP прокси с HTTPS через CONNECT.
* Режим «Отдельные приложения» и режим «Весь компьютер · TUN».
* PowerShell с переменными прокси и TZ по выходному IP.
* Обычный Firefox с выбранным VPN-профилем и настроенным прокси.
* Проверка IP, географии, оценки доверия и рисков через Net.Coffee.
* Квота Mozilla, статистика соединения и журнал текущего запуска.
* Сохранение профиля, сервера, порта и режима подключения.
* Восстановление связи с выбранным сервером.

## Требования

* Windows 11 x64, на которой проверена текущая сборка.
* [.NET Runtime 10 x64](https://dotnet.microsoft.com/download/dotnet/10.0).
* [Windows App Runtime 2.6.4 x64](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads).
* [Python 3.12 или новее](https://www.python.org/downloads/windows/), доступный через PATH.
* Установленный Firefox и профиль с авторизацией Mozilla и доступным встроенным VPN.
* Свободный локальный порт и право записи в папку приложения и выбранный профиль Firefox.
* Для TUN нужны права администратора. Сетевой движок sing-box включён в поставку.

CLI устанавливаются отдельно. Если .NET или Windows App Runtime отсутствует, инструкция появляется до запуска интерфейса. Python и файлы ядра проверяются при старте приложения.

## Начало работы

1. Распакуйте всю поставку в папку с правом записи.
2. Запустите `FoxBridge.WinUI.exe`. Сохраните рядом папки `Assets`, `Backend`, `Tools` и остальные файлы поставки.
3. Выберите профиль Firefox и нажмите «Загрузить профиль».
4. Выберите сервер и режим подключения.
5. Включите прокси или TUN и дождитесь успешной проверки IP. Для терминала также требуется корректный TZ.
6. В режиме «Отдельные приложения» откройте защищённый терминал для CLI или Firefox для сайтов.

Перед сменой профиля, сервера, режима или порта отключите соединение. Подключение всегда включается вручную.

### Отдельные приложения

Кнопка терминала открывает PowerShell с адресом локального прокси и переменной TZ. Их наследуют дочерние процессы. Уже работающие приложения не получают новое окружение. Программы должны поддерживать переданные переменные. Терминал не является песочницей и не блокирует прямые подключения программ, которые игнорируют прокси.

TZ берётся из Net.Coffee. Если сервис не вернул пояс, применяется приблизительное соответствие стране. Источник показан под кнопками запуска. Часы и часовой пояс Windows не меняются.

### Firefox с выбранным VPN-профилем

«Открыть Firefox» использует тот же профиль, который загружен для получения данных VPN. Сохраняются логины, cookies, история и расширения. Firefox восстанавливает предыдущие окна и вкладки средствами своего менеджера сеансов. Приватные вкладки и сеансы, которые сам Firefox не сохраняет, восстановить нельзя.

Перед запуском штатно закройте все окна Firefox с выбранным профилем. Профиль не копируется. Уже работающие экземпляры с другими профилями не закрываются. Повторное нажатие кнопки открывает пустую вкладку в запущенном экземпляре.

HTTP и HTTPS идут через локальный прокси FoxBridge. Системный TUN для этого не требуется. WebRTC, HTTP/3 и предзагрузка DNS временно отключаются. Звонки через WebRTC могут не работать. Встроенный VPN Firefox и расширения могут управлять собственным прокси, учитывайте их настройки при выборе маршрута.

FoxBridge временно дописывает свои сетевые настройки к существующему `user.js`. Прежние значения сохраняются в `foxbridge-preferences.json` внутри профиля и восстанавливаются после завершения Firefox. Логины, cookies, история и посторонние настройки не откатываются. После аварии оставшийся журнал используется при следующем запуске этого профиля через FoxBridge. Не удаляйте журнал вручную.

При закрытии FoxBridge запущенный им экземпляр получает штатную команду закрытия для сохранения сеанса. Если Firefox показывает диалог или продолжает работать, завершите его работу вручную. При отключении прокси сетевой доступ через него прекращается.

### Часовой пояс и язык для веб-версии Claude

FoxBridge запускает Firefox обычным способом, без RemoteAgent и WebDriver. Он не подменяет TZ и локаль браузера. Настройка TZ для терминала на браузер не распространяется.

Если требуется согласовать TZ и язык браузера с выбранным подключением при работе с веб-версией Claude, установите подходящее расширение в тот же VPN-профиль Firefox. Например, [Chameleon от sereneblue](https://addons.mozilla.org/en-US/firefox/addon/chameleon-ext/) поддерживает подмену TZ и настройки языка. Возможности и ограничения описаны в [документации расширения](https://sereneblue.github.io/chameleon/wiki/options/). Автор указывает ограничение подмены TZ английской локалью и неполное покрытие способов определения времени.

Расширение устанавливается и настраивается пользователем. FoxBridge его не загружает и не управляет им. Это рекомендация для настройки окружения, а не официальное требование Anthropic. Совпадение языка с географией IP не обязательно. Подмена не гарантирует доступ к Claude или прохождение Cloudflare, а некоторые расширения сами мешают проверкам. Проверяйте разрешения устанавливаемого расширения и совместимость сайтов.

### Весь компьютер через TUN

1. Запустите FoxBridge от имени администратора. При обычном запуске появится закрываемое предупреждение, подключение TUN будет недоступно.
2. Загрузите профиль Firefox и выберите сервер.
3. Выберите «Весь компьютер · TUN» и подключитесь.
4. Для завершения отключите TUN или закройте FoxBridge.

До перенаправления трафика приложение проверяет выходной IP и получает корректную оценку Net.Coffee через локальный прокси. При ошибке TUN не включается. Успешная проверка сразу отображается в статистике.

TUN направляет TCP интернет соединений в локальный прокси. DNS передаётся через HTTPS внутри туннеля. Остальной UDP, попавший в TUN, блокируется. Игры, звонки и приложения, которым необходим UDP, могут не работать. Loopback, локальная сеть, специальные маршруты и явная привязка к другому интерфейсу могут обходить TUN.

При отключении или аварии TUN обычный доступ Windows к сети возвращается. Постоянный kill switch отсутствует. После смены Wi-Fi, Ethernet или другого VPN переподключите TUN. Фоновые загрузки тоже расходуют квоту Mozilla. TUN не меняет часовой пояс, язык Windows и настройки браузеров.

### Важно: авторизация в Codex и Claude

> [!IMPORTANT]
> Для входа из CLI подготовьте браузер заранее. Страница авторизации должна открываться через нужное подключение.

1. Сделайте Firefox браузером по умолчанию в Windows.
2. Заранее запустите Firefox с тем же профилем, который используется в FoxBridge.
3. Для обычного Firefox включите встроенный VPN с той же локацией, которая выбрана в FoxBridge. Оставьте его включённым до завершения входа.
4. Запускайте авторизацию из защищённого терминала FoxBridge и убедитесь, что ссылка открылась в подготовленном браузере.

Если используется кнопка «Открыть Firefox», сначала закройте обычные окна этого профиля, затем запустите его через FoxBridge. В этом случае браузер уже получает прокси приложения. Запуск не меняет браузер по умолчанию и не гарантирует выбор профиля для внешней ссылки. Не включайте одновременно несколько маршрутов без проверки фактического выхода.

## FAQ

### Прокси действует на весь компьютер?

В режиме «Отдельные приложения» через него работают запущенный Firefox и программы, поддерживающие окружение защищённого терминала. Для TCP трафика остальных программ используйте TUN с правами администратора.

### Почему TUN недоступен?

Для подключения требуются права администратора, загруженный профиль, выбранный сервер и успешная проверка IP и Net.Coffee. Описание причины отображается в интерфейсе.

### Почему Firefox просит закрыть профиль?

Один профиль нельзя безопасно открыть двумя независимыми экземплярами. Закройте все его окна обычным способом. Чужие процессы и другие профили FoxBridge не завершает.

### Сохранятся ли вкладки и логины?

Используется исходный выбранный профиль. Cookies, сохранённые пароли и история остаются в нём. Вкладки восстанавливает Firefox из сохранённого сеанса. Приватные вкладки не сохраняются.

### Подмена TZ для браузера осталась?

Нет. Автоматическая подмена локали и TZ через RemoteAgent удалена. Для браузера доступны ручная настройка и расширения. PowerShell продолжает получать переменную TZ по данным Net.Coffee. Программы могут её игнорировать.

### Нужны ли расширения для Claude Code?

Расширения Firefox работают только в браузере и не меняют окружение Claude Code или Codex CLI. Для согласования TZ и локали веб-версии Claude можно установить расширение в выбранный профиль. Официального требования устанавливать его у Anthropic нет.

### Почему Cloudflare повторяет проверку?

Причиной могут быть сеть, IP, настройки браузера или расширения. Текущий запуск Firefox не использует WebDriver. Пройдите проверку вручную в актуальном Firefox, проверьте разрешение JavaScript и влияние расширений. Если проблема остаётся, обратитесь в поддержку сайта. Оценка Net.Coffee не гарантирует прохождение проверки.

### Почему квота уменьшается без работы в терминале?

Квота общая для аккаунта Mozilla. Её расходуют проверки IP, другие устройства, Firefox VPN и фоновые программы в TUN. Локальная статистика FoxBridge относится только к текущему подключению.

### Что произойдёт после отключения?

Локальный прокси перестанет обслуживать подключения. При отключении TUN вернётся обычный маршрут Windows. Терминал может остаться открытым со старым адресом прокси. Перезапустите его из приложения для нового подключения.

### После аварии Firefox сохранил старый прокси. Что делать?

Закройте все окна выбранного профиля и снова откройте его через FoxBridge. Приложение восстановит параметры из `foxbridge-preferences.json` перед новым запуском. При сообщении о конфликте `user.js` сохраните этот файл и журнал для ручного восстановления.

### Подмена железа осталась?

Нет. Модуль, интерфейс и зависимости экспериментального спуфа удалены. FoxBridge не скрывает аккаунт, идентификаторы установки или содержимое отправляемых запросов.

## Оценка и ограничения

Net.Coffee получает проверяемый публичный IP и возвращает собственную оценку рисков. Это не рейтинг Anthropic. При отсутствии результата цвет нейтральный. Цвет полученной оценки соответствует диапазонам Net.Coffee.

FoxBridge не расшифровывает HTTPS и не устанавливает сертификат перехвата. Приложение не гарантирует анонимность, отсутствие утечек для любых программ или доступ к конкретным сервисам. Соблюдайте условия Mozilla и используемых сервисов.

## Сборка

Для разработки нужны .NET SDK 10, Windows SDK и средства сборки WinUI 3. Используются Windows SDK 10.0.26100.0 и Windows App SDK 2.6.4.

Команды из корня проекта в PowerShell:

```powershell
& ./development/Install-TunEngine.ps1
dotnet build development/FoxBridge.WinUI/FoxBridge.WinUI.csproj -c Debug -p:Platform=x64
& ./development/Publish-Release.ps1
```

Готовая поставка обновляется в единственной папке `FoxBridge-WinUI`. Личные настройки сохраняются. Debug и промежуточные файлы остаются в `development`.

Для явно запрошенного архива релиза:

```powershell
& ./development/Package-Release.ps1 -Version 0.8.0
```

Архивы создаются в `development/release-artifacts` и не включаются в Git. Личные настройки в них не входят.
